# Customer research — read-only (Claude Code with a browser)

Use in Claude Code with a connected browser (for example, the Chrome extension). Replace what’s between `< >`.

```
Search for <industry> in <city>. Open the first 3 sites that appear.
Make a table with: name, website, phone number, and one thing the site does poorly
(example: no WhatsApp button, slow to load, no prices listed).
Rules: read only. Don’t contact anyone, fill out forms, click “buy” or “send,” or log in. If a page asks for information, stop and let me know.
At the end, show me the table and where you got each piece of information.
```

Filled-in example: `Search for bakeries in Austin.`
