# Investigación de clientes — solo lectura (Claude Code con navegador)

Úsalo en Claude Code con un navegador conectado (por ejemplo, la extensión de Chrome). Cambia lo que está entre `< >`.

```
Busca <rubro> en <ciudad>. Abre los primeros 3 sitios que aparezcan.
Arma una tabla con: nombre, sitio web, teléfono y algo que el sitio hace mal
(ejemplo: no tiene botón de WhatsApp, tarda en abrir, no muestra los precios).
Reglas: solo lee. No contactes a nadie, no completes formularios, no hagas clic en
"comprar" ni "enviar", no inicies sesión. Si una página pide datos, detente y avísame.
Al final, muéstrame la tabla y de dónde sacaste cada dato.
```

Ejemplo completo: `Busca panadería en Bogotá.`
