# Pesquisa de clientes — só lendo (Claude Code com navegador)

Use no Claude Code com um navegador ligado (por exemplo, a extensão do Chrome). Troque o que está entre `< >`.

```
Procure <ramo> em <cidade>. Abra os 3 primeiros sites que aparecerem.
Monte uma tabela com: nome, site, telefone e uma coisa que o site faz mal
(exemplo: não tem botão de WhatsApp, demora para abrir, não mostra preço).
Regras: só leia. Não contate ninguém, não preencha formulário, não clique em
"comprar" nem "enviar", não faça login. Se uma página pedir dados, pare e me avise.
No fim, me mostre a tabela e de onde tirou cada informação.
```

Exemplo preenchido: `Procure padaria em Porto Alegre.`
